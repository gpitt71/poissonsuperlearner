# poissonsuperlearner: Poisson Super Learner

Provides tools for fitting piecewise-constant hazard models for survival
and competing risks data, including ensemble hazard estimation via the
Super Learner framework. The package supports estimation of survival
functions and absolute risk predictions from fitted cause-specific
hazard models. For the Super Learner framework see van der Laan, Polley
and Hubbard (2007)
[doi:10.2202/1544-6115.1309](https://doi.org/10.2202/1544-6115.1309) .
