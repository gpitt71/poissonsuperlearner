# Print method for `base_learner`

Prints a compact description of the fitted base learner, including the
learner type, the time-grid used, and (optionally) the fitted model
object for a given cause.

## Usage

``` r
# S3 method for class 'base_learner'
print(x, cause = 1, ...)
```

## Arguments

- x:

  `base_learner` object returned by
  [`fit_learner()`](https://gpitt71.github.io/poissonsuperlearner/reference/fit_learner.md).

- cause:

  `numeric(1)` or `NULL`. Which cause to print the fitted model for. If
  `NULL`, prints one line per cause (classes only) instead of printing
  the full fitted objects.

- ...:

  Passed to the underlying fitted object
  [`print()`](https://rdrr.io/r/base/print.html) method when `cause` is
  a single integer.

## Value

Invisibly returns `x`.

## Examples

lrn <- Learner_glmnet(
  covariates = c("sex", "value_LDL"),
  lambda = 0.01,
  cross_validation = FALSE
)
bl <- fit_learner(
  d,
  learner = lrn,
  id = "id",
  status = "status_cvd",
  event_time = "time_cvd",
  number_of_nodes = 3
)
print(bl, cause = NULL)
